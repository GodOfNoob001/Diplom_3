# UI-тестирование веб-приложения Stellar Burgers

## 📋 О проекте

Проект автоматизации UI-тестирования для веб-приложения Stellar Burgers - сервиса по заказу космических бургеров.

## 🛠 Технологический стек

- **Python 3.11+** - язык программирования
- **Selenium WebDriver** - автоматизация браузера
- **Pytest** - фреймворк для тестирования
- **Allure Framework** - создание отчетов
- **Page Object Pattern** - паттерн проектирования
- **WebDriver Manager** - управление драйверами браузеров
